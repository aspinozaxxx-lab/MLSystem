Г.1	Алгоритм расчета точности полученного результата семантической сегментации
Тестовая разметка применяется для оценки качества работы модели распознавания ОКС путем пообъектного сравнения тестовой разметки и распознанных объектов по метрике F1-Score object. Сравнение тестовой разметки и распознанных объектов выполняется с учетом спрямления углов (опция «полигонизация»).
Пообъектная F1-Score object считается по формуле (1) 
ObjF1 = (2TP)/ (2*TP + FP + FN)  (1)
где:
ObjF1 – пообъектная мера F1-Score object;
TP – количество верно локализованных объектов целевого класса;
FP – количество ошибочно обнаруженных объектов целевого класса, которым нет соответствия в тестовой разметке;
FN – количество не обнаруженных объектов целевого класса, имеющихся в тестовой разметке. 
Алгоритм расчета меры F1-Score object для пообъектного сравнения тестовой разметки и распознанных объектов представлен на рисунке ниже (см. Рисунок Г.1), пояснения приведены по тексту ниже.
 
Рисунок Г.1	Блок-схема определения TP, FP и FN для расчета пообъектной ObjF1
На рисунке (см. Рисунок Г.1) используются следующие обозначения: 
	Pi – распознаваемый объект; 
	i – порядковый номер распознаваемого объекта; 
	M – количество распознаваемых объектов целевого класса; 
	Si – максимальное значение индекса Жаккара для распознаваемого объекта Pi и множества объектов целевого класса из тестового набора данных Lj; 
	J – индекс Жаккара, определяемый по формуле (2); 
	Lj – объекты целевого класса из тестового набора данных; 
	j – порядковый номер объекта целевого класса из тестового набора данных;
	B – количество объектов целевого класса в тестовом наборе данных; 
	FP – ошибочно обнаруженные объекты целевого класса, которым нет соответствия в тестовой разметке;
	TP – количество верно локализованных объектов целевого класса;
	argmax – значение аргумента, при котором выражение достигает максимума;
	FN – не обнаруженные объекты целевого класса, имеющиеся в тестовой разметке.
При этом объект Pi считается верно локализованным, если в тестовой разметке существует объект Lj, для которого индекс Жаккара J(Pi, Lj) > 0,5, определяемый по формуле (2), которую в данном случае можно представить как J (Pi,Lj) = |Pi∩Lj|/|Pi∪Lj|.
J (Pi,Lj) = |Pi∩Lj|/|Pi∪Lj (2)
Где:
|Pi∩Lj| – площадь пересечения классифицированных объектов и тестовой разметки;
|Pi∪Lj| – площадь объединения классифицированных объектов и тестовой разметки.
Алгоритм расчета точности полученного результата семантической сегментации должен быть визуализирован с использованием прикладного интерпретатора для расчета метрики 
F1-Score object, открываемого с помощью веб-браузера с использованием Jupyter notebook.
